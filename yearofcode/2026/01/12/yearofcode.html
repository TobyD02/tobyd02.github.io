Year of Code!

Jan 12, 2026

This year, I’ve decided to commit to what I’m calling a “Year of Code”. Each week I will pick a new project topic and attempt to build some MVP by the end of the week - documenting everything here. I haven’t quite ironed out the details yet, so this is very much a “figure it out as I go along” kind of project.

So… what are the constraints? Firstly - obviously, each project must be completed within the week. I’ll be considering a project finished when there is:

  • Some presentable deliverable, whether that be a webpage, app, video, etc…
  • A blog post documenting the process of research and development, and an evaluation of the project
  • Some ideas for future development, things I would add/remove, related topics I would explore, etc…

The only thing I need now is some topics and project ideas - making sure manage my scope to something reasonably accomplishable. I also want to make sure that these ideas are open-ended, similar to prompts for game jams. If the prompt is broad enough, I can allow my ideas to lead my development as they come to me.

Some topics that are peaking my interests:

  • Music:
    • Explore Digital Signal Processing, perhaps creating some sort of sound visualizer using FFT, etc…
    • Harmony analysis or recommendation, maybe having live analysis whilst playing via midi
  • Game Development:
    • Attempting to recreate the first level of the original Super Mario Bros
    • Exploring State Machines and intelligent AI
  • Machine Learning:
    • Exploring Evolutionary AI and Reinforcement Learning
    • Applications of Small Language Models (SLMs)
  • Creative Coding:
    • Visualising different algorithms (e.g. Fractals, Voronoi, etc…) using both 2D (P5.js) and 3D (Blender) libraries.
  • Productivity:
    • A project management / todo tracking app - potentially integrating with GitHub to track across branches
